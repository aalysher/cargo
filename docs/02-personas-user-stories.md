# 02. Персоны, user stories, разрез MVP

## Персоны

### 1. Айгуль — клиент-покупатель (основная для MVP)
- 25–38, заказывает на Taobao / Poizon / 1688, 2–4 раза в месяц, веса 0,5–10 кг.
- Цели: купить дешевле, получить без нервов, знать цену и срок заранее.
- Боли: не знает, где посылка; финальная цена ≠ расчёту; менеджер не отвечает; путается в адресе склада и коде.
- Сценарии: получила адрес склада → отправила продавцом; посчитала доставку; отслеживает до выдачи; спрашивает «это можно перевозить?».
- Интерфейс: Telegram Mini App.

### 2. Марат — предприниматель с партиями (v2)
- Малый опт, партии 50–500 кг, регулярные отправки.
- Цели: опт-ставка, стабильные сроки, документы, история партий и платежей.
- Боли: опт-тариф выбивается в личке, нет истории, объёмный вес непредсказуем.
- В MVP закрывается «как есть» + личный менеджер; модель данных учитывает (тип клиента, опт-тарифы — v2).

### 3. Динара — оператор склада/менеджер (админка)
- Принимает посылки, взвешивает, меняет статусы, отвечает клиентам.
- Цели: быстро обработать входящие, ничего не потерять, не отвечать 50 раз «где мой заказ».
- Боли: учёт в тетради/Excel + чаты; постоянные «где мой заказ»; ошибки в весах.
- Интерфейс: веб-админка.

## User stories

### MVP (один разработчик, 2–4 недели)
| # | Story | Персона | Оценка |
|---|---|---|---|
| M1 | Открываю TMA и уже авторизован (Telegram initData) | Айгуль | 2–3 д |
| M2 | Вижу адрес склада + личный код с копированием в 1 тап | Айгуль | 1 д |
| M3 | Считаю доставку (вес, линия) по тарифам из БД | Айгуль | 2 д |
| M4 | Создаю заявку (что везём, вес, треки, комментарий) | Айгуль | 2–3 д |
| M5 | Вижу список заказов и таймлайн статусов | Айгуль | 2–3 д |
| M6 | Получаю сообщение от бота при смене статуса с deep link | Айгуль | 1–2 д |
| M7 | Задаю вопрос по заказу (чат = диалог с ботом, контекст прикладывается) | Айгуль | 1 д |
| M8 | Оператор видит заявки и меняет статусы (приём, вес, отгрузка, выдача) | Динара | 3 д |
| M9 | Оператор редактирует тарифы | Динара | 1 д |
| M10 | Оператор видит профиль клиента рядом с заказом | Динара | 1 д |

Итого ≈ 16–19 рабочих дней.

### v2
Оплата онлайн + чеки; выкуп по ссылке с мгновенным расчётом; фотоотчёт (N фото бесплатно); консолидация с расчётом экономии; опт-кабинет; выбор ПВЗ/окна выдачи; расширенный чат поддержки (SLA).

### Потом
Интеграция с трекерами (Cainiao и др.); складская автоматика (ШК, терминал); промокоды/рефералка; мультиязычность; аналитика; маршрутизация курьеров; PWA-версия сайта.

## Не-goals MVP
❌ онлайн-оплата, ❌ выкуп, ❌ фотоотчёт как фича (фото — вручную оператором), ❌ опт-кабинет, ❌ интеграции с маркетплейсами.
