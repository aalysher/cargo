# 03. UX и экраны

## Пользовательский путь

```
Открыл бота → /start → «Открыть приложение»
   ↓
TMA: авто-вход по initData (0 кликов) → Онбординг (1-й запуск)
   ↓
Главная → «Мой адрес склада» (копия в 1 тап) → покупка на Taobao
   ↓
Посылка приехала на склад → бот: «Посылка получена» → deep link в карточку
   ↓
Главная → «+ Новая заявка» → оператор подтверждает
   ↓
Статусы: на складе → отгружено → в пути → в Бишкеке → готово к выдаче
   ↓
Бот: «Готово к выдаче» → забрал → «Выдано»
```

До первой ценности (калькулятор): 1 тап. До заявки: 2 тапа.

## Навигация (нижнее меню, ≤5 пунктов)

```
🏠 Главная   📦 Заказы   🧮 Калькулятор   👤 Профиль
```

«Адрес склада» — карточка на Главной (+ в профиле). «Чат» — кнопка внутри карточки заказа и на Главной (диалог с ботом).

## Экраны MVP

### Онбординг (1-й запуск)
- Назначение: 15 секунд пользы — «как это работает» + адрес склада.
- Блоки: 3 шага (покупаете → шлёте на склад → получаете); MainButton «Начать».
- Пустое: n/a. Загрузка: скелетон. Ошибка (initData не прошёл): «Откройте приложение через бота @имя».

### Главная 🏠
- Блоки: приветствие + счётчик посылок в пути; карточки активных заказов с прогрессом; плитки «Мой адрес склада», «Посчитать доставку»; мини-FAQ.
- Главное действие: «+ Новая заявка» — Telegram MainButton (снизу).
- Пустое: «Здесь появятся ваши посылки» + CTA. Загрузка: скелетоны. Ошибка: retry-блок.

### Калькулятор 🧮
- Блоки: линия (авто/авиа), вес, расчётный вес, расшифровка (ставка × вес + сборы), итог крупно.
- Главное действие: «Оформить заявку с этими данными».
- Пустое: «Введите вес». Ошибка: inline-подсказки; тарифы не загрузились → retry.

### Новая заявка (bottom sheet)
- Блоки: что везём (1 строка), тип груза (чипы), вес (авто из калькулятора), треки (0..n), комментарий.
- Главное действие: MainButton «Отправить заявку».
- Ошибка: inline-валидация; сервер отклонил → toast + локальный черновик.

### Заказы 📦
- Блоки: фильтры-сегменты (Активные/Доставляются/Выданы/Все), список карточек (номер, дата, вес, бейдж, мини-прогресс).
- Пустое: «Пока нет заказов» + CTA. Загрузка: скелетоны. Ошибка: retry.

### Карточка заказа
- Блоки: статус крупно + ETA; вертикальный таймлайн; треки (копируются); вес/объём/цена; кнопка «Написать по этому заказу».
- Deep link из бота ведёт прямо сюда. Ошибка «Заказ не найден» → назад.

### Мой адрес склада
- Блоки: карточки по полям (получатель, адрес, телефон, личный код — крупно), копирование каждого поля + «Скопировать всё», инструкция для продавца.
- Главное действие: копирование (+ haptic).

### Профиль 👤
- Блоки: имя/телефон (request_phone), адрес склада, правила перевозки (что можно/нельзя), о компании, поддержка.

## Админка (веб)
| Экран | Главное действие |
|---|---|
| Заказы (таблица + фильтры) | сменить статус, вписать фактический вес, треки |
| Карточка заказа | таймлайн, комментарий, данные клиента |
| Тарифы | ставки, коэффициент объёмного веса, сборы |
| Клиенты | поиск по Telegram/телефону/коду, история |

## Принципы
- Минимум шагов: заявка — 1 экран; калькулятор → заявка с переносом данных.
- Всё главное в зоне большого пальца: таббар и MainButton снизу, цели ≥44px.
- Статус за 2 секунды: на Главной бейдж + прогресс без входа в заказ.
- Никаких перегруженных форм: 4 обязательных поля в заявке.
- TMA-нативность: тема Telegram, haptics, BackButton.
